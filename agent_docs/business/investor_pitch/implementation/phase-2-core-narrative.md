# Phase 2 — Core investor narrative

## Goal

Implement the complete static investor argument in the conventional sequence, using real structured content and System C presentation before adding complex interactions.

## Sections

### Hero/thesis

Implement:

- company purpose;
- “mastery, not coverage” standard;
- concise instructional-LMS definition;
- Base/Core/Premier system line only if it does not distract from the initial product;
- primary `Discuss the pre-seed` CTA;
- secondary `View product state` CTA.

System C treatment: full-width ruled frame, sparse mark, oversized Instrument Sans headline, mono metadata rail. No generic hero illustration.

### Problem

Implement the family/classroom comparison with a shared center rail:

- curriculum package schedules but does not adapt;
- classroom attention cannot be continuous;
- parent/teacher must diagnose, enforce, revisit, and record;
- founder's Abeka experience as a labeled example, not market proof.

### Product and instructional loop

Implement a readable static diagram first:

- adult direction;
- planner;
- specialist tutor;
- habit checks;
- revision loop;
- evidence record;
- transfer/project;
- adult exception review.

Every node includes a state badge. The LLM is not visually central.

### How it teaches

Use four to six ruled examples:

- asks before it tells;
- correction before progression;
- reasoning/units/evidence/grammar/vocabulary;
- transfer across subjects;
- off-screen projects;
- evidence behind mastery.

### Evidence

Render three clearly separated tiers:

1. research basis;
2. learner evidence model;
3. Primer company evidence plan.

The company tier must state `NOT YET MEASURED` where appropriate.

### Market summary

Render the four non-additive expansion layers:

- Base homeschool;
- Core public-school-family population;
- Premier NAIS;
- Premier premium-private cohort.

Use textual equations and caveats before Phase 3's calculator.

### GTM

Implement the adoption ladder:

- family Base;
- family Core;
- ESA/microschool;
- Premier family/elite learning support;
- LTI/Clever pilot;
- tuition-embedded or academic-core deployment.

### Competition

Use a category matrix:

- generic AI;
- subject tutor;
- mastery tool;
- homeschool package;
- conventional LMS;
- human tutoring/consulting;
- Primer.

Show methodology and avoid unverified universal checkmarks.

### Founder/team

Implement:

- homeschool student in Peru;
- Abeka homeschool parent;
- current parent-builder;
- eBackpack/LMS integration proof;
- compact 18-month team plan;
- role ownership for founder, educator/product owner, and product/platform builder.

Salary is shown in the use-of-funds model, not as defensive copy in the founder story.

### Current state

Render `LIVE`, `IN DEVELOPMENT`, and `PLANNED` columns from structured data. Display time/capital invested and initial use candidly.

### Business model and ask

Render:

- Base/Core/Premier responsibility ladder;
- institutional rows separately;
- $3.5M pre-seed / 18 months;
- bottom-up people and operating plan;
- seed-readiness scorecard;
- source/diligence links;
- contact CTA.

## Responsive design

- desktop uses ruled multi-column layouts;
- mobile collapses to the identical logical order;
- tables receive stacked semantic representations below narrow breakpoints;
- diagrams have ordered-list equivalents;
- sticky elements must never obscure headings or source links.

## Tests

- every section renders from structured data;
- all headings and anchors are unique;
- all claims requiring sources expose source links;
- all product capabilities expose status;
- no modeled market values are automatically totaled;
- mobile reading order matches desktop argument;
- screenshots for every section in dark/light and desktop/mobile;
- content text snapshot or schema test to detect accidental claim deletion.

## Exit criteria

- a complete static page can be sent to an investor for content review;
- the argument is understandable without hover, animation, or deep routes;
- all current-stage caveats are visible;
- System C treatment is consistent across every section;
- no implementation work remains necessary to evaluate narrative quality.
