# Bundled System C fonts

Instrument Sans and IBM Plex Mono are licensed under the SIL Open Font License 1.1.

- `ofl_instrument_sans.txt` — Instrument Sans (variable, weights 400–700)
- `ofl_ibm_plex_mono.txt` — IBM Plex Mono Regular and Medium

Do not replace these files with unlicensed copies. The Compose theme loads them from `res/font`.
